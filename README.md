# GARRISYNC — Alliance Operating System

> A commercial SaaS platform that helps competitive mobile-game alliances (starting with *Call of Dragons*) run their operations: membership, scheduling, events, attendance, leadership requests, and recruitment — through a Discord bot and a web-based Command Center.

## What GARRISYNC does

Alliance leaders in large online games coordinate hundreds of players across time zones, usually through scattered chat messages and spreadsheets. GARRISYNC turns that into a structured operating system:

- **Discord integration** — managed invites and join onboarding, slash commands, leadership briefs, an "Ask Garrisync" knowledge assistant, and requests routed to the right leadership department with reply/resolve workflows.
- **Web Command Center** — a leadership dashboard and player home, availability planning across time zones, event scheduling with RSVPs and reminders, and attendance tracking.
- **Operations tooling** — recurring-battle scheduling, season planning, a recruitment pipeline, free calculators, and multi-language support.
- **Multi-tenant operation** — separate customer alliance environments, each with its own configuration and data boundaries.
